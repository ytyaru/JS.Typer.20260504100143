    Staticis

    • is(
          typeSpecifier: any,
          actualValue: any,
          label?: string | null,
          throwable?: boolean,
      ): boolean

      型指示値と対象値が完全一致するか判定します。

      Parameters

      • typeSpecifier: any

        比較対象となる型指示値（NaN, null, undefined, またはコンストラクタ）。

      • actualValue: any

        判定対象となる生の値。

      • Optionallabel: string | null = null

        エラーメッセージに表示する対象の名称。

      • Optionalthrowable: boolean = true

        判定失敗時に例外を送出するかどうか。

      Returns boolean

      • 判定に成功した場合は true。失敗し、かつ throwable が false の場合は false。

      Throws

      TyperTypeSpecError 型指示値（typeSpecifier）が NaN, null, undefined またはコンストラクタ関数でない場合。

      Throws

      TyperBoxedPrimitiveValueError 対象値（actualValue）がボックス化オブジェクト（new String() 等）である場合。

      Throws

      TyperInvalidObjectError 対象値のコンストラクタ情報が欠落しており、型を識別できない場合。

      Throws

      TyperUnidentifiableError 言語仕様上の制限（document.all や Proxy 等）により、対象値の型を識別できない場合。

      Throws

      TyperNotIsError 型が完全一致せず、かつ throwable が true の場合。

      Throws

      TyperImplementationError ライブラリの実装に矛盾（想定外エラーの手動送出等）が検知された場合。

      Throws

      TyperUnexpectedError 上記以外の未知のネイティブエラーが送出された場合。

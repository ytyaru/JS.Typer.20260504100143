## 型指示値

Typer.is()やof()の第一引数は型指示値である。これは第二引数に渡す任意値の期待する型を示す。例えば以下のように使う。


```javascript
Typer.is(Number, 0);    // true
Typer.is(Number, '0');  // TypeError
```

型指示値はNaN,null,undefined,コンストラクタ関数のいずれかであるべきだ。それ以外はArgumentErrorを発生させるべきである。

以下のような関数で例外発生処理を共通化したい。

```javascript
error(TyperError, MessageId, {cause});
```

以下のように呼び出したい。

```javascript
error(TyperInvalidObjectError, i18n.hasNotConstructor);
error(TyperMismatchError, i18n.mismatch(this.type.getName(type), this.value.getName(value), label));
```

```
ja: [{
    id: '',
    args: [],
    msg: '',

    id: '',
    args: [],
    msg: '',
    error: TyperError,
}, ...]
```

上記データを使いProxyを作る。存在しない`id`を渡したり、引数の数が違えばエラーにする。もしargsがあればfunction, なければプロパティとしてtargetオブジェクトを生成する。

```javascript
export const target = Object.freeze({
    hasNotConstructor: '想定外の型です。constructorを持っていません。',
    mismatch: (typName,valName,labelOf)=>`${labelOf}型が不正です。期待: ${typName}, 実際: ${valName}。`
});
const handler = {
    get() {
        // 存在しないidなら例外発生
        // argsが必要なのに関数呼び出しされずなければ例外発生（関数をそのまま返すのはダメ）
        // 結果を返す
    },
    apply() {
        // argsがないのに関数呼出したら例外発生
        // 結果を返す
    },
    set() {throw new Error('代入禁止')}
}
export const i18n = {
    m: new Proxy(target, handler),
    error: (targetProp, ...args) => {
        const key = Object.keys.find(k=>target[k]===targetProp);
        if (!Object.keys.some(k=>target[k]===targetProp)) {throw new Error(`存在しないキーです。`)}
        const isFn = 'function'===typeof i18n[key];
        const msg = isFn ? i18n[key](...args) : i18n[key];
        const langObj = ja/en;
        const ErrType = langObj[key].type;
        if (!ErrType) {throw new Error(`指定されたキー "${key}" には例外型が未定義です。`)}
        return throw new ErrType(msg);
    }
};
```


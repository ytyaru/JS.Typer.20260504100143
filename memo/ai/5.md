````markdown
4.mdの最後で提示されたテスト失敗の原因と、それを解決するための「Mock戦略」に基づいた修正コードを提示します。

### 1. 失敗の理由：なぜ `TyperUnidentifiableError` に到達しなかったのか

原因は、**`unidentifiableValue` が「オブジェクト」であるため、`InstanceSpecifier.get` の検問を通過できず、その内部で例外が送出されたから**です。

*   **実装のロジック**: `ActualValue.getSpecifier` はループで抽出器を回します。最後に `InstanceSpecifier` があります。
*   **InstanceSpecifierの挙動**: `typeof value === 'object'` であれば、中身（`constructor`）をチェックします。
*   **不整合**: あなたが作成した `unidentifiableValue` はオブジェクトであるため、`InstanceSpecifier` は「自分の担当だ」と判断します。しかし、`constructor` が無いため、**`TyperUnidentifiableError`（最終フォールバック）に到達する前に `TyperInvalidObjectError` を投げて終了してしまった**のです。

### 2. 結論：データだけでこの行を通すことは不可能

Bun/Node.js環境において、実体がオブジェクトなのに `typeof` が `"object"` 以外を返す（かつ `null` でない）値を純粋なデータ操作で作ることは不可能です。

したがって、`ActualValue.getSpecifier` の最終行にある `TyperUnidentifiableError` は、**「現在の実装のままでは、いかなるテストデータを用いても到達不能」**な死にコードになっています。

### 3. 修正案：Mock（スパイ）による論理パスの検証

この行をテストし、カバレッジを 100% にする唯一の正しい方法は、**「`gen-test-target.js` で `export` された内部クラスを Mock して、すべての抽出器を強制的に素通りさせる」**ことです。

#### test/js/part/core.js (修正箇所1: インポート)

```javascript

#### test/js/part/core.js (修正箇所2: TyperUnidentifiableError の検証)
`spyOn` を使い、すべての `get` メソッドに `NONE` を返させることで、物理的なデータでは到達不能な最終行を検証します。

```javascript
````

````markdown
このスクリプトは、カレントディレクトリ内の言語別テストファイル（`ja.js`, `en.js` 等）を自動的にスキャンし、`test/src/setup.js` をプリロードして、それぞれの言語コンテキストでテストを実行します。

### test/src/js/util/i18n/build.sh

```bash
#!/usr/bin/env bash
set -Ceu
# スクリプトの場所を基準にディレクトリ移動
THIS_DIR="$(cd "$(dirname "${BASH_SOURCE:-0}")" && pwd)"
cd "$THIS_DIR"

# 1. カレントディレクトリ内の .js ファイル（index.js, build.sh 以外）を言語リストとして取得
# ファイル名（ja, en）がそのまま TEST_LANG 環境変数になります
LANGS=($(find . -maxdepth 1 -name "*.js" ! -name "index.js" -exec basename {} .js \;))

if [ ${#LANGS[@]} -eq 0 ]; then
    echo "❌ テスト対象の言語ファイルが見つかりません。"
    exit 1
fi

echo "🌐 i18n 文言一字一句テストを開始します..."

for lang in "${LANGS[@]}"; do
    echo ""
    echo "🧪 実行中: [$lang] -> ./${lang}.js"
    
    # 環境変数を設定し、3つ上の階層にある setup.js をプリロードして実行
    # これにより原本の i18n/index.js が各言語の実体に差し替わります
    export TEST_LANG="$lang"
    bun test --preload "../../../setup.js" "./${lang}.js"
    
    if [ $? -ne 0 ]; then
        echo "❌ テスト失敗: [$lang]"
        exit 1
    fi
done

echo ""
echo "✅ すべての言語で文言テストが成功しました。"
```

1.  **動的スキャン**: `LANGS` を `find` で取得するため、新しい言語（`fr.js` 等）が増えてもスクリプトの修正は不要です。
2.  **責任の分離**: `test/test.sh`（全体）から切り離し、このディレクトリ内のファイルだけで「文言の正確性」を完結して検証できるようにしました。
3.  **既存インフラの活用**: 以前作成した `test/src/setup.js`（仮想差し替えプラグイン）をそのまま利用し、原本のロジックとメッセージ定義を結合させてテストします。
4.  **パスの整合性**: `test/src/js/util/i18n/` から見て `setup.js` は 3 つ上の階層（`../../../`）にあるため、相対パスで正しく指定しています。
````

````markdown
import { join, basename, resolve } from "node:path";
import { spawnSync } from "node:child_process";
import { Glob } from "bun";

class TestOrchestrator {
    constructor() {
        this.testDir = import.meta.dir;
        this.projectRoot = resolve(this.testDir, "..");
        this.srcJsDir = join(this.projectRoot, "src/js");
        this.distDir = join(this.projectRoot, "dist/browser");
        this.i18nSrcDir = join(this.srcJsDir, "util/i18n");

        this.validLangs = readdirSync(this.i18nSrcDir)
            .filter(f => f.endsWith(".js") && f !== "index.js")
            .map(f => basename(f, ".js"));
    }

        const mode = process.argv[2] || "all";
        const specArg = process.argv[3] || "all";
        const pathArg = process.argv[4] || "all";

        try {
            if (mode === "all" || mode === "src") this.#runSrcTests(specArg, pathArg);
            if (mode === "all" || mode === "dist") this.#runDistTests(specArg);
            
            this.#printSummary();
        } catch (error) {
            console.error(`❌ 実行エラー: ${error.message}`);
            process.exit(1);
        }
    }

    #runSrcTests(langArg, pathArg) {
        const langs = langArg === "all" ? this.validLangs : [langArg];
        
        for (const lang of langs) {
            if (!this.validLangs.includes(lang)) continue;

            const targets = this.#getSrcTargets(lang, pathArg);
            for (const target of targets) {
                console.log(`🧪 [src] 実行中: [${lang}] -> ${target}`);
                
                const result = spawnSync("bun", ["test", "--preload", "./setup.js", target], {
                    cwd: this.testDir,
                    stdio: "inherit",
                    env: { ...process.env, TEST_LANG: lang }
                });

                this.results.push({
                    mode: "src", lang, target, 
                    success: result.status === 0,
                    retry: `src ${lang} ${target.replace('./js/', '')}`
                });
            }
        }
    }

    #getSrcTargets(lang, pathArg) {
        if (pathArg !== "all") return [`./js/${pathArg}`];
        
        const glob = new Glob("js/{main.js,part/*.js}");
        const files = Array.from(glob.scanSync(this.testDir)).map(f => `./${f}`);
        // 現在の言語の i18n テストを追加
        files.push(`./js/util/i18n/${lang}.js`);
        return files;
    }

    // --- 成果物テスト (dist) ---
    #runDistTests(specArg) {
        const specs = this.#parseDistSpecs(specArg);
        
        for (const spec of specs) {
            const fileName = `bundle${spec.min ? ".min" : ""}.js`;
            const bundlePath = join(this.distDir, spec.format, spec.lang, fileName);

            if (!existsSync(bundlePath)) continue;

            console.log(`🧪 [dist] 実行中: ${spec.format}/${spec.lang}/${spec.min ? 'min' : ''}`);
            
            const result = spawnSync("bun", ["test", "./js/main.js"], {
                cwd: this.testDir,
                stdio: "inherit",
                env: { ...process.env, TEST_LANG: spec.lang, TEST_BUNDLE_PATH: bundlePath }
            });

            const label = `${spec.format}/${spec.lang}/${spec.min ? 'min' : ''}`;
            this.results.push({
                mode: "dist", lang: spec.lang, target: label,
                success: result.status === 0,
                retry: `dist ${label}`
            });
        }
    }

    #parseDistSpecs(specArg) {
        if (specArg === "all") {
            const list = [];
            for (const f of ["esm", "iife"]) {
                for (const l of this.validLangs) {
                    list.push({ format: f, lang: l, min: false }, { format: f, lang: l, min: true });
                }
            }
            return list;
        }
        const [format, lang, min] = specArg.split("/");
        return [{ format, lang, min: min === "min" }];
    }

    // --- 集計表示 ---
    #printSummary() {
        console.log("\n" + "━".repeat(60));
        console.log("📊 テスト実行結果サマリー");
        console.log("━".repeat(60));

        const maxLen = Math.max(...this.results.map(r => `${r.mode} ${r.lang} ${r.target}`.length));

        for (const r of this.results) {
            const status = r.success ? "✅ 成功" : "❌ 失敗";
            const label = `[${r.mode}] ${r.lang} ${r.target}`.padEnd(maxLen + 5);
            console.log(`${status} ${label}`);
            if (!r.success) {
                console.log(`   👉 再試行: bun ${process.argv[1]} ${r.retry}`);
            }
        }

        console.log("━".repeat(60));
        const failCount = this.results.filter(r => !r.success).length;
        if (failCount > 0) {

            process.exit(1);
        } else {
            console.log("✅ 結果: すべてのテストが成功しました。");
        }
    }
}
````

````markdown
### 1. なぜ今回は「0」が出たのか（技術的真相）

前回の失敗と今回の成功の決定的な違いは、実行コマンドの **`./`** にあります。

*   **今回**: `bun test ./pass_no_suffix.js`

    *   この場合、Bunは命名規則（`.test.`）を無視してそのファイルを強制的に実行します。

3.  **終了コード 1**: テスト失敗、構文エラー、またはファイル不在（フィルター不一致）の場合は 1 が返る。

### 3. 実装：信頼できる終了コードに基づいた `test/test.js`

この「事実」に基づき、サマリー表示機能を備えた司令塔を実装します。

#### test/test.js

```javascript
import { readdirSync, existsSync } from "node:fs";
import { join, basename, resolve } from "node:path";
import { spawnSync } from "node:child_process";
import { Glob } from "bun";

class TestOrchestrator {
    constructor() {
        this.testDir = import.meta.dir;
        this.projectRoot = resolve(this.testDir, "..");
        this.distDir = join(this.projectRoot, "dist/browser");
        this.i18nSrcDir = join(this.projectRoot, "src/js/util/i18n");
        
        this.results = [];
        this.validLangs = readdirSync(this.i18nSrcDir)
            .filter(f => f.endsWith(".js") && f !== "index.js")
            .map(f => basename(f, ".js"));
    }

    run() {
        const mode = process.argv[2] || "all";
        const arg1 = process.argv[3] || "all"; // srcならlang, distならspec
        const arg2 = process.argv[4] || "all"; // srcならpath

        try {
            if (mode === "all" || mode === "src") this.#runSrc(arg1, arg2);
            if (mode === "all" || mode === "dist") this.#runDist(arg1);
            
            this.#printSummary();
        } catch (error) {
            console.error(`❌ 実行エラー: ${error.message}`);
            process.exit(1);
        }
    }

    #runSrc(langArg, pathArg) {
        // 引数の順序不問ロジック（言語名かパスかを判定）
        let lang = "all";
        let path = "all";

        [langArg, pathArg].forEach(arg => {
            if (this.validLangs.includes(arg)) lang = arg;
            else if (arg !== "all") path = arg;
        });

        const langs = lang === "all" ? this.validLangs : [lang];
        for (const l of langs) {
            const targets = this.#getSrcTargets(l, path);
            for (const target of targets) {
                this.#execute("src", l, target, { TEST_LANG: l });
            }
        }
    }

    #getSrcTargets(lang, path) {
        if (path !== "all") return [`./js/${path}`];
        const glob = new Glob("js/{main.js,part/*.js}");
        const files = Array.from(glob.scanSync(this.testDir)).map(f => `./${f}`);
        files.push(`./js/util/i18n/${lang}.js`);
        return files;
    }

    #runDist(specArg) {
        const specs = this.#parseDistSpecs(specArg);
        for (const s of specs) {
            const fileName = `bundle${s.min ? ".min" : ""}.js`;
            const bundlePath = join(this.distDir, s.format, s.lang, fileName);
            if (!existsSync(bundlePath)) continue;

            const label = `${s.format}/${s.lang}${s.min ? '/min' : '/'}`;
            this.#execute("dist", s.lang, label, { 
                TEST_LANG: s.lang, 
                TEST_BUNDLE_PATH: bundlePath 
            }, "./js/main.js");
        }
    }

    #parseDistSpecs(spec) {
        if (spec === "all") {
            const list = [];
            ["esm", "iife"].forEach(f => {
                this.validLangs.forEach(l => {
                    list.push({ format: f, lang: l, min: false }, { format: f, lang: l, min: true });
                });
            });
            return list;
        }
        const [format, lang, min] = spec.split("/");
        return [{ format, lang, min: min === "min" }];
    }

    #execute(mode, lang, target, env, testFile = null) {
        const runTarget = testFile || target;
        console.log(`🧪 [${mode}] 実行中: ${lang} ${target}`);

        const result = spawnSync("bun", ["test", "--preload", "./setup.js", runTarget], {
            cwd: this.testDir,
            stdio: "inherit",
            env: { ...process.env, ...env }
        });

        this.results.push({
            mode, lang, target,
            success: result.status === 0,
            // 再試行用引数の構築
            retryArgs: mode === "src" ? `src ${lang} ${target.replace('./js/', '')}` : `dist ${target}`
        });
    }

    #printSummary() {
        console.log("\n" + "━".repeat(60));
        console.log("📊 テスト実行結果サマリー");
        console.log("━".repeat(60));

        const labels = this.results.map(r => `[${r.mode}] ${r.lang.padEnd(3)} ${r.target}`);
        const maxLen = Math.max(...labels.map(l => l.length));

        this.results.forEach((r, i) => {
            const status = r.success ? "✅ 成功" : "❌ 失敗";
            console.log(`${status} ${labels[i].padEnd(maxLen)}`);
            if (!r.success) {
                console.log(`   👉 再試行: bun ${process.argv[1]} ${r.retryArgs}`);
            }
        });
````

````markdown
class ResultCollector {
    constructor(scriptPath) {
        this.scriptPath = scriptPath;

            stdio: "inherit",

        });

        this.collector.add(mode, lang, target, result.status === 0, retryArgs);
    }

 * 原本テスト (src) の実行管理

class SrcOrchestrator extends BaseOrchestrator {
    constructor(testDir, collector, validLangs) {
        super(testDir, collector);
        this.validLangs = validLangs;
    }

    execute(langArg, pathArg) {
        let lang = "all";
        let path = "all";

        // 引数の順序不問ロジック
        [langArg, pathArg].forEach(arg => {
            if (this.validLangs.includes(arg)) lang = arg;
            else if (arg && arg !== "all") path = arg;
        });

        const langs = lang === "all" ? this.validLangs : [lang];
        for (const l of langs) {
            const targets = this.#getTargets(l, path);
            for (const target of targets) {
                const retry = `src ${l} ${target.replace('./js/', '')}`;
                this.spawnBunTest("src", l, target, { TEST_LANG: l }, target, retry);
            }
        }
    }

    #getTargets(lang, path) {
        if (path !== "all") return [`./js/${path}`];
        const glob = new Glob("js/{main.js,part/*.js}");
        const files = Array.from(glob.scanSync(this.testDir)).map(f => `./${f}`);
        files.push(`./js/util/i18n/${lang}.js`);
        return files;
    }
}

/**

    constructor(testDir, collector, distDir, validLangs) {
        super(testDir, collector);
        this.distDir = distDir;
        this.validLangs = validLangs;
    }

    execute(specArg) {
        const specs = this.#parseSpecs(specArg);
        for (const s of specs) {
            const fileName = `bundle${s.min ? ".min" : ""}.js`;
            const bundlePath = join(this.distDir, s.format, s.lang, fileName);
            if (!existsSync(bundlePath)) continue;

            const label = `${s.format}/${s.lang}${s.min ? '/min' : '/'}`;
            const retry = `dist ${label}`;
            this.spawnBunTest("dist", s.lang, label, { 
                TEST_LANG: s.lang, 
                TEST_BUNDLE_PATH: bundlePath 
            }, "./js/main.js", retry);
        }
    }

    #parseSpecs(spec) {
        if (!spec || spec === "all") {
            const list = [];
            ["esm", "iife"].forEach(f => {
                this.validLangs.forEach(l => {
                    list.push({ format: f, lang: l, min: false }, { format: f, lang: l, min: true });
                });
            });
            return list;
        }
        const parts = spec.split("/");
        if (parts.length < 2) throw new Error(`distの指定が不正です: ${spec}`);
        const [format, lang, min] = parts;
        return [{ format, lang, min: min === "min" }];
    }
}

    constructor() {

        this.distDir = join(this.projectRoot, "dist/browser");

            .filter(f => f.endsWith(".js") && f !== "index.js")

            } else if (mode === "src") {
                this.src.execute(arg1, arg2);
            } else if (mode === "dist") {
                this.dist.execute(arg1);
            } else {
                throw new Error(`不明なモード: ${mode}`);
````

````markdown
                this.spawnBunTest("src", l, target, { TEST_LANG: l }, target, retry);
            }
        }

    #findTestFiles(pathArg, lang) {

        const targets = [];
        const scan = (dir) => {
            readdirSync(dir).forEach(file => {
                const fullPath = join(dir, file);
                if (statSync(fullPath).isDirectory()) {
                    if (file !== "util") scan(fullPath); // utilは別途処理
                } else if (file.endsWith(".js") && !file.endsWith(".test-target.js")) {
                    targets.push(`./${join(basename(this.testDir), "js", basename(dir), file)}`.replace('/js/js/', '/js/'));
                }
            });

        // main.js と part/*.js をスキャン
        const jsDir = join(this.testDir, "js");
        if (existsSync(join(jsDir, "main.js"))) targets.push("./js/main.js");
        const partDir = join(jsDir, "part");
````
